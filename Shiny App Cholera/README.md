# Geovisualisation of Cholera Incidence Data in Cameroon Using Shiny Package in R

### Brief description:
The dashboard aims to visualize the occurrence of cholera in Cameroon at a regional level with the help of various maps and plots to analyze and enable better anticipatory action to mitigate the spread of the disease.

It consists of the following features:
1. **Cholera Incidence map**: The main tab contains a map visualizing the no. of cases in Cameroon with the help of a time slider.
2. **Outbreak plots**: The second tab contains an overview of the cases and deaths due to cholera in Cameroon, visualized using a bar and line plot and a violin plot in two sub-tabs.
3. **Data**: The Data tab allows users to view, search, sort and download the raw data to create the charts and plots.
4. **About**: The tab contains information about the GitHub Source code and the data sources used for creating the visualizations.

The dashboard can help support research and decision-making in the health domain rapidly and effectively with a better interpretation of health information. It plays an essential role in the outbreak situation management and communication to the audience.
